# 新手教程：5 分钟给 T3 Code 装上中文界面

不需要会编程。照着做，复制粘贴命令就行。

> ⚠️ 这是非官方补丁。它会修改你电脑上 T3 Code 安装目录里的两个文件，并先自动备份。随时可以一条命令还原，见 [第 6 步](#6-想恢复英文)。

---

## 0. 你需要准备什么

| 需要 | 怎么确认 |
|---|---|
| Windows 电脑（64 位） | 本补丁只在 Windows x64 上测试过 |
| 已安装 **T3 Code (Beta)** | 开始菜单能搜到它 |
| **Node.js 22 或更高** | 见下一步 |

> 已在 T3 Code (Beta) **0.1.7** 上验证。版本差得多的话，个别文字可能没翻译，或者菜单没汉化，都不影响使用。

---

## 1. 安装 Node.js（已经装过的跳过）

1. 打开 <https://nodejs.org>，下载 **LTS** 版本并安装，一路“下一步”即可。
2. 装完后按 `Win` 键，搜索 **PowerShell**，打开它（普通权限就行，不需要管理员）。
3. 输入下面的命令并回车：

   ```powershell
   node -v
   ```

   看到 `v22.x.x` 或更高（比如 `v24.18.0`）就对了。显示“无法识别”说明没装好，关掉 PowerShell 重新打开再试，或重启电脑。

---

## 2. 下载本项目

**方式 A：下载压缩包（推荐新手）**

1. 打开项目主页 <https://github.com/sgyueran/T3-code-CHS>。
2. 点绿色的 **Code** 按钮 → **Download ZIP**。
3. 把压缩包解压到一个**路径里没有中文和空格**的位置，例如 `D:\T3-code-CHS`。

**方式 B：用 git**

```powershell
git clone https://github.com/sgyueran/T3-code-CHS.git
```

---

## 3. 进入项目目录，安装依赖

在 PowerShell 里依次输入（把路径换成你自己解压的位置）：

```powershell
cd D:\T3-code-CHS
npm install
```

等几十秒，出现 `added xx packages` 就完成了。只需要做这一次。

> 如果提示 **“无法加载文件 npm.ps1，因为在此系统上禁止运行脚本”**：把命令里的 `npm` 换成 `npm.cmd`，例如 `npm.cmd install`。后面的 `npm run ...` 同理。

---

## 4. 打补丁

### 4.1 先完全退出 T3 Code ⚠️ 最容易漏的一步

只点窗口右上角的 ✕ **不一定退出**，程序可能还留在系统托盘或后台。请这样做：

1. 右键任务栏右下角的托盘图标（`^` 展开里找 T3 Code），选 **退出**；
2. 或者按 `Ctrl + Shift + Esc` 打开任务管理器，找到所有名为 **T3 Code (Beta)** 的进程，逐个“结束任务”。

不退出的话，脚本会拒绝执行并提示：`T3 Code 正在运行……请先完全退出后再打补丁`。

### 4.2 运行补丁

```powershell
npm run patch
```

成功时会看到类似这样的输出：

```
词条 5288，模板 631，跳过 0 → dist/zh-CN.js
[t3code-chs] 备份 server.asar → server.asar.orig
[t3code-chs] server.asar 已注入（运行时 375 KB）
[t3code-chs] 备份 app.asar → app.asar.orig
[t3code-chs] app.asar 已汉化：字符串规则 40/40，菜单角色 23 处
[t3code-chs] 完成。T3 Code 0.1.7 @ C:\Users\...\t3code
```

**怎么看有没有问题：**

- 最后一行出现“**完成**”就成功了。
- “字符串规则 40/40” 表示菜单和对话框的汉化规则全部命中。如果是 `35/40` 并伴有“警告 命中 0/1 ……”，说明你的 T3 Code 版本和补丁适配的不完全一样：界面仍然是中文，只是少数菜单项/弹窗可能还是英文。

### 4.3 如果你的 T3 Code 装在别的位置

默认位置是 `%LOCALAPPDATA%\Programs\t3code`。装在别处的话，指定目录（目录里要有 `resources` 文件夹）：

```powershell
npm run patch -- --dir "D:\Apps\t3code"
```

> 不确定安装位置？右键开始菜单里的 T3 Code → 更多 → 打开文件位置，一路找到那个带 `T3 Code (Beta).exe` 的文件夹。

---

## 5. 打开 T3 Code，检查效果

正常启动 T3 Code。你应该能看到：

- 侧边栏的“搜索”、已有对话列表上的“标记完成”等都是中文，鼠标悬停在左下角几个图标上，提示文字也是中文；
- 输入框提示变成“随便问点什么。@ 文件，$ 技能，/ 命令”；
- 顶部菜单是“文件 / 编辑 / 视图 / 窗口 / 帮助”；
- 打开设置页，各分区都是中文。

**以下内容保持原样，这是故意的，不是漏翻：**

- 代码块、终端里的内容；
- 聊天里 AI 的回复和你自己发的消息；
- 你输入框里敲的字；
- 品牌名和模型名（T3 Code、Claude、Codex 等）。

---

## 6. 想恢复英文

同样要先**完全退出 T3 Code**，然后：

```powershell
cd D:\T3-code-CHS
npm run restore
```

看到 `已还原 server.asar` 和 `已还原 app.asar` 就回到原版了。

只想**临时**看英文，不用还原：在 T3 Code 里按 `Ctrl + Shift + I` 打开开发者工具，进入 **Console（控制台）**，输入

```js
__t3i18n.disable()
```

回车后页面会刷新成英文。想再切回中文就输入 `__t3i18n.enable()`。

---

## 7. T3 Code 更新之后

T3 Code 自动更新会把安装目录换成新文件，**汉化会丢失**，界面变回英文。这时：

1. 完全退出 T3 Code；
2. 在项目目录再运行一次 `npm run patch`。

脚本会自动识别“应用已经更新”并重新备份，**不需要先 restore**。

建议顺便更新一下本项目（重新下载 ZIP，或在项目目录里 `git pull`），因为新版本可能多出一些新文字，词典会随之补充。

## 8. 常见问题

**Q：提示“T3 Code 正在运行（包括托盘/后台进程）”**
A：没退干净，见 [4.1](#41-先完全退出-t3-code-️-最容易漏的一步)。确认任务管理器里没有任何 `T3 Code (Beta)` 进程再试。

**Q：提示“找不到 T3 Code 安装目录”**
A：你的安装位置不是默认路径，用 `--dir` 指定，见 [4.3](#43-如果你的-t3-code-装在别的位置)。

**Q：`node` / `npm` “无法识别”**
A：Node.js 没装好，或装完没重开 PowerShell。关掉重开；还不行就重启电脑。

**Q：打了补丁，界面还是英文**
A：依次检查：① 打补丁后有没有**重新启动** T3 Code；② `npm run patch` 最后有没有“完成”；③ 是不是 T3 Code 刚更新过，重新 patch 一次；④ 在开发者工具 Console 里输入 `__t3i18n.size`，有数字（约 5000）说明翻译脚本已加载，输入 `localStorage.getItem("t3code:i18n:off")` 如果得到 `"1"`，说明之前被关闭过，执行 `__t3i18n.enable()`。

**Q：有些地方还是英文 / 译文读着别扭**
A：正常。词典约 5300 条，大部分是机器翻译，没有逐条人工校对。欢迎到项目的 Issues 反馈，或者直接改 `dict/manual.json`（见下面）。

**Q：会不会把我的聊天记录、账号搞坏？**
A：不会。补丁只往界面里加一段翻译脚本，并替换几十条菜单文字，不读写你的会话数据。原文件都备份在安装目录的 `resources` 里，名为 `server.asar.orig` 和 `app.asar.orig`，请不要手动删除它们。

**Q：杀毒软件报警了怎么办？**
A：补丁会改写安装目录里的 `.asar` 文件，个别杀毒软件可能提示。代码全部开源，可以自行阅读 `scripts/patch.mjs`。心里不踏实就别用。

**Q：我想自己改某句译文**
A：打开 `dict/manual.json`，加一行 `"英文原文": "你想要的中文"`，保存后按 [第 4 步](#4-打补丁) 重新 `npm run patch` 即可。这个文件优先级最高，会盖过其他译文。句子里有变量的写成 `{0}`，例如 `"Pin {0}": "置顶 {0}"`。
